## Requirement Statement

The project must document and justify key security design decisions using Zero Trust principles and relevant standards/literature.

## Rationale

The proposal positions this as an academic investigation grounded in NIST SP 800-207 and related references.

## Acceptance Interpretation

The final documentation includes explicit rationale tying major design choices to Zero Trust principles and cited references.
