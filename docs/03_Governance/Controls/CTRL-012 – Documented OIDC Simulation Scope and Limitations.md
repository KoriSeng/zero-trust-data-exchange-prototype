## 1. Control Description
Document what the simulated OIDC providers do and do not represent (claims, token lifetimes, rotation behaviour, error handling) and treat gaps as explicit investigation limitations.

## 2. Control Objective
Maintain research integrity by preventing over-claiming and by ensuring limitations are clearly stated.

## 3. Implementation Details
Maintain an integration plan that defines simulation behaviours and records deviations from typical enterprise IdPs.

## 4. Evidence and Verification
A written section exists describing simulation scope and limitations and is referenced in evaluation findings.
