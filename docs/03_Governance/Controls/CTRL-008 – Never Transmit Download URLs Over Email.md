## 1. Control Description

Ensure download URLs are displayed only once in the UI and are not distributed through email or chat.

## 2. Control Objective

Reduce unintended persistence and re-sharing of download URLs.

## 3. Implementation Details

Threat model mitigation specifies: URL displayed once in UI and never emailed.

## 4. Evidence and Verification

Review notification content and UI workflow to confirm no download URL is included in out-of-band messages.
